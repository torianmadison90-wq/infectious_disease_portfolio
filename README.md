# Infectious Disease Portfolio

**Question:** How did adult COVID-19 vaccination coverage differ by age, race/ethnicity, and state during the 2024-25 season?

**Data:** CDC National Immunization Survey, Adult COVID Module (RespVaxView), 2024-25 archive season. Download from data.cdc.gov (not included here due to size).

**Tools:** SQL (SQLite), Python, Tableau (in progress)

**Files:** `queries.sql` has the SQL queries with findings.
